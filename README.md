# Quran O Itrat Academy - Complete Website

A comprehensive Islamic education website built with React frontend and Node.js backend.

## Features
- Course management system
- Library with preview/download functionality  
- Study materials management
- Article system
- Contact and admission forms with admin management
- Admin dashboard with statistics
- Secure authentication

## Setup
1. Backend: cd quran-o-itrat-backend-node && npm install && npm start
2. Frontend: cd quran-o-itrat-frontend && pnpm install && pnpm dev

## Default Admin Credentials
- Username: admin
- Password: admin123

## Technology Stack
- Frontend: React 18, Tailwind CSS, Vite
- Backend: Node.js, Express, MongoDB
- Authentication: JWT with bcrypt
